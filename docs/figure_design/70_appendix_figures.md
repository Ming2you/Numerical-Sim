# Appendix Figure Inventory

Use the appendix for complete scenario-by-scenario detail. Main-text figures
should remain selective.

For each active scenario:

- interval total TTT;
- cumulative total TTT;
- urban TTT;
- freeway TTT;
- delay;
- throughput;
- terminal vehicles;
- boundary queue;
- ramp queue;
- off-ramp queue;
- urban accumulation;
- freeway density.

## Appendix B. Ramp-Specific Figures

For each ramp:

- metering rate time-series;
- ramp queue time-series;
- ramp discharge time-series;
- adjacent urban queue;
- metering rate vs freeway density;
- metering rate vs adjacent urban queue.

## Appendix C. VSL And Freeway Segment Figures

For each direction and segment:

- VSL time-series;
- speed time-series;
- density time-series;
- flow time-series;
- speed-density or flow-density scatter;
- space-time speed/density heatmap.

## Appendix D. Signal Figures

For each controlled intersection:

- movement-level green time;
- green ratio by movement group;
- queue-green lagged scatter;
- inflow/outflow green ratio;
- phase split diagram.

## Appendix E. Offset Figures

For each corridor:

- offset timeline;
- time-space progression diagram if supported;
- cumulative departures;
- throughput comparison.
