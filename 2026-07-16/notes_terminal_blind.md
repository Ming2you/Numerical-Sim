# 2026-07-16 ★terminal이 눈멀어 있었다 — 고치니 사고 축 반전

## 결론
**사용자 진단 적중.** terminal(far) 항이 `v_free`·상수 `g_fw=300`으로 박혀 **차선폐색·과포화를
전혀 못 봤다**. state(ρ·유효차선)에서 유도하도록 고치니 **170_incident_w가 −10.45% 패 →
+1.21% 승**으로 뒤집히고, **최악이 −10.45% → −0.95%로 10배 개선**, 평균도 +3.73% → +4.74%.

오늘 실패한 다섯 시도(δ·스텝게이팅·채널분리·수요스위치·전역재탐색)는 전부 **cross를 언제
켜냐**를 물었다. 진짜 문제는 거기가 아니라 **terminal이 절벽을 못 보는 것**이었다.

## 수정 (FAR_STATE_AWARE=1, 새 튜닝 상수 없음)

- `t_trav = Σ_i ℓ / V(ρ_i)`  (`desired_speed_kmh`)
- `g_fw   = min_i cap(lanes_i)`  (병목 세그먼트 용량 — **폐색이면 자동 하락**)

기본 False=상수식. **비트동일 검증 통과**(155_skew_w PFO 1791.2960 = 기존 1791.3).

## 열린 가설 (야간 큐가 답함)

terminal이 눈먼 자리. 맞다면 terminal 수정 후 **cross OFF가 전 셀 승** → 오늘의 cross 소동은
전부 증상 치료였던 것.
- `_farsa_crosson` (state-aware × cross ON) ← 이 가설의 직접 검증

  재는 자기모순 해소. 태스크 #44.
- 190_w는 `_farsa`에서 누락 — 두 야간 배치가 포함.
