# 분석 세션 시작 프롬프트 (복사해서 그대로 붙여넣기)

---

너는 교통제어 논문(계층 Stackelberg MPC, 도시-고속도로 혼합망)의 **사후분석 전담** 세션이다.
시뮬레이션 런은 다른 컴퓨터가 담당한다 — **이 컴퓨터에서는 시뮬레이션을 재실행하지 않는다.**
네 일은 이미 확보된 런 데이터에서 논문 그림·표·수치를 뽑는 것이다.

## 시작 절차 (순서 엄수)

1. repo: `https://github.com/Ming2you/NRF-3.git` (또는 로컬 클론), 브랜치
   `feature/segment-agents-13p`, 작업 디렉터리 `2026-07-17/paper_package/`.
2. **`ANALYSIS_PLAN_FINAL.md`를 처음부터 끝까지 읽는다.** 특히 §0.5 "컬럼 함정 사전"은
   분석 시작 전에 암기 수준으로 숙지할 것 — 아래 규율 3번이 이것 때문에 존재한다.
3. `data/README.md`로 4팔(arm) × 6셀 구조를 확인한다.
4. 첫 작업 전에 **검산 게이트**를 통과한다: `data/walk_mvg/<5셀>`의 run_log에서
   wTTT(= cumulative_total_ttt[마지막 행] − [step==20 행])와 개선%를 계산해
   계획서 §0.2의 수치(+5.10 / +11.14 / +9.81 / +3.03 / +9.38%)와 **소수 둘째 자리까지
   일치**하는지 확인하고 결과를 보고할 것. 불일치하면 분석을 멈추고 원인부터 보고.

## 작업 규율 (이 프로젝트에서 실측으로 얻은 교훈 — 위반 금지)

1. **측정하지 않은 메커니즘을 주장하지 않는다.** 이 프로젝트의 추론-선행 오귀속 기록이
   1/22였다. 그림에서 패턴이 보여도, 그 원인은 데이터로 확인한 것만 쓰고 나머지는
   "미검증 가설"로 명시한다. 모르면 모른다고 쓴다.
2. **모든 수치는 재현 스크립트와 함께.** 표·그림의 모든 숫자는 어느 파일의 어느 컬럼에서
   어떤 식으로 나왔는지 스크립트로 남긴다(`scripts/` 폴더에 저장).
3. **컬럼 이름을 믿지 않는다.** `leader_lambda_np_committed`는 가격이 아니라 boolean이고,
   `N_UF_star`는 realized지 intent가 아니다(intent는 `leader_candidate_best_intent_*`).
   §0.5 사전에 없는 컬럼을 처음 쓸 때는 값 분포(고유값 개수, 범위)부터 찍어 성격을
   확인한 뒤 사용한다.
4. **채점 규약 고정**: WARM=20, wTTT 윈도우, PFO 기준선은 §0.4 표의 수치 사용.
   다른 정의를 임의로 도입하지 않는다.
5. 결과물은 `2026-07-17/paper_package/analysis/` 아래에 정리한다:
   `analysis/figures/`(PDF+PNG), `analysis/tables/`(md+csv), `analysis/scripts/`,
   `analysis/notes.md`(진행·발견·미해결). 완료 단위마다 커밋 — 메시지는
   `YYYY-MM-DD: <섹션> <내용>` 형식, 같은 브랜치에 푸시.

## 산출물 (우선순위 순 — 계획서의 해당 절 참조)

**P1. §1 거시 표 (표 1)** — 5셀 × walk-MVG: wTTT, PFO 대비 개선%, 완주/잔존 대수,
mean/max step compute. NC/WU-CD-F/PFO 열은 데이터가 아직 없으므로 자리만 만들고
"런 대기"로 표기(런 머신이 채운다).

**P2. §2b 200_w 회복 서사 그림 (그림 후보 1순위)** — 3팔(farsa_ref / box300_vsl10_ref /
walk_mvg) × 200_w: (i) Σmetering 시계열, (ii) 리더 intent 시계열, (iii) ③ 대비 누적 TTT
차이. 검증 목표치: 회복기(step 40+) intent가 ③ 5485→6000 / box 3190 고착 / walk 5805.
캡션 메시지: "채점 맹점은 walk로 교정(intent 해방), 잔여 손실은 rate limit의 물리."

**P3. §2a metering 평활성 그림** — pd4_ref vs walk_mvg, 190_w, 램프 4개 metering 시계열.
검증 목표치: pd4 per-ramp max|Δ|=1199(풀스팬), walk_mvg ≤300.

**P4. §3a bang-bang 정량 표/그림** — pd4_ref(박스 없음)에서 rung 분류
{375,525,750,1050,1500}: 내부 rung 선택률(목표 재현치 0/160), 끝점 비율, 가격 부호→끝점
적중률(80~85%). run_log `wu_b3_meter_price_R_*` 부호와 대조.

**P5. §2c 레버 이동 감사 표** — 4팔 × {green, VSL, metering} per-step max|Δ| vs 명목 한계.
farsa_ref의 VSL 50(위반)과 walk_mvg의 10.0(교정)이 핵심 대비.

**P6. §3c dual 감사 미니 표** — farsa_ref에서 `wu_faithful_lambda_P`와
`leader_lambda_uf_committed`의 고유값·비영 스텝 수(목표 재현치: 둘 다 비영 0/40).

**P7. §5 한계 절 초안** — 계획서 §5의 6개 항목을 위 그림·표 번호에 연결한 서술 초안
(analysis/notes.md에). 새 주장 추가 금지 — 계획서에 있는 측정 사실만 조립.

P1~P3이 끝나면 중간 보고를 하고, 사람이 우선순위를 조정할 수 있게 한다.
