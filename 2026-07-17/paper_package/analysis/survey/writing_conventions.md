## 축별 핵심 관찰

**축1 단락 해부학**: 첫 문장은 목적 선언형("무엇을 검증하기 위해") 또는 그림 지시형("…는 Fig N에").
요지는 **미괄식** — 증거를 다 보여준 뒤 조건 한정어를 단 결론("especially in the strongly
coupled cases"). 관찰→해석 전환 표지어 정형: "reveals that / implying / which is consistent
with"(IEEE, 관계절 접합) vs 관찰·해석 문장 분리(TR-B).

**축2 개선치 표기**: 절대값+% 한 문장 결합(Hegyi 표준형), 비교 분모를 캡션에 수식으로
(Ding: (IC−NC)/NC), 시나리오별 보고가 기본·풀링 금지(음수 셀이 지워짐). **결정론 매크로
논문(Wu·Hegyi·VdB·Zhai)은 시드·유의성 언급 0회가 관례** — 반면 확률 시뮬레이터(K-E,
Haddad)는 10-replication 필수. "significant"는 수십%급에만, 작은 효과는 "slightly/not obvious".

**축3 메커니즘 논증**: 지배 패턴 = **액추에이터 궤적 + 상태 궤적 + 시점 일치 + 반사실 패널**
(Wu의 Fig7-10 시점 정렬이 교과서). **이원 인과 어휘** — 측정·조작된 채널만 "causes/leads
to/contributes to", 미측정 정합은 "consistent with/coincides with". 집계는 표, 메커니즘은
대표 런 1개 심층 해부("예시적 비교를 위해 Replication 1을…" — K-E). 명령-실현 괴리는
숨기지 않고 원인 귀속(증거 종류까지 명시).

**축4 정직성 관례(구체 사례)**: VdB07 Table 1의 **음수 셀 그대로 게재** + "트레이드오프의
증거"로 재프레이밍(total 양수 근거). Haddad13은 **실패 구성(D-MPC gridlock)을 그림 3장으로
결과 본문에 전면 공개**하고 다음 설계의 동기로 삼음. 개선율의 조건 의존성 선언 + 검증 런
(수요 −10%로 실측). 분산화 손실 상한 명시("7% 미만"). 실패 공개 → 사용 조건 처방 전환
(Hegyi msm 진동 → "이 경우 VSL 권고").

**축5 실시간 논증**: 정형 = "전형값+최악값+제어주기 대비"(Hegyi 6s/10s vs 60s). Wu는
**"C. CPU Time" 전용 소절 + 스킴별 평균·최대 표 + 하드웨어(3.6GHz/32GB)·솔버(CPLEX/SQP)·
반복 상한(Nash 5회) 공개**. **최대값으로 임계값 주장**을 거는 것이 요점.

**축6 공정 비교**: 베이스라인마다 **"어떤 격차를 격리하는 도구인지" 목적 선언**(Wu §V-B:
NCD=협력의 가치, CC=분산화 손실+계산). 비교 가능성 근거 문장(Hegyi: "최종 정상상태가 같도록
시나리오 선택"). **권한 차이의 등화 실험**(Hegyi msm LB 매칭 → 권한/조정 격차 분해의 정통
계보). 근사 베이스라인 자백("-like" 접미). 이길 수 없는 대상은 **상한(upper bound)으로 명명**.

## §별 처방 (뼈대 문장·함정은 원문 보고 참조 — 요지만)

- **§1**: 컨트롤러 도입 시 격차-격리 목적 선언 / 시나리오별 분해·음수 셀 유지·§5 포워딩 /
  "significant" 금지(등급 어휘로) / 분모 캡션 수식.
- **§2**: 시점 정렬 서사 + 사건 트리거 구조(rate-limit이 물리는 순간=사건) + 대표 런 해부 +
  이원 인과 어휘 + **귀속 유보 명문화**("We refrain from attributing the residual…").
- **§3**: ordered vs actual 괴리 공개 + 가격×이동폭 환산 규범 승격 + 서사 없는 부호 반전
  해석 금지.
- **§4**: 조건 의존성 선언+검증 런 / 임계점은 **구간(bracket)**으로("between 169% and 205%") /
  "for the network considered here" 소절당 1회.
- **§5**: 실패 영역을 **결과 블록**으로(지도의 언어 — "지도의 가치는 어디서 작동하지 않는지도
  그리는 데 있다") / 실패→운영 처방 착지 / 결정론·플랜트=예측모델 자백 **1회만**(반복 사과
  금지) / 한계 절에 새 데이터 투입 금지(재서술만).

## 7계명 (즉시 적용)
1. 소절은 목적/그림 지시로 열고, 요지는 조건 한정어 단 미괄로.
2. 절대값+% 한 문장, 분모는 캡션 수식.
3. 시드 무언급이 장르 관례, 단 결정론 선언 1회.
4. 측정 채널만 인과 동사, 나머지 "consistent with", 귀속 유보 명문.
5. 음수 셀은 표에 남기고 지도 언어로 재프레이밍.
6. 계산은 최대값 vs 제어주기 + 하드웨어·솔버·반복 공개.
7. 베이스라인마다 격리하는 격차를 선언 — 권한/조정 분해는 Hegyi 2005 계보임을 팔 것.
